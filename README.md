# Digital Taxonomies: An Educational Sorting Game

**[Play the game online](https://yuanpan2025.github.io/DHGames/)**

An interactive browser game for exploring how classification systems work—and what gets lost when real-world objects are turned into digital categories.

> “Taxonomies are essentially sorting exercises—some categories make more sense than others depending on context, purpose, and what gets lost when real objects are digitized.”

## How It Works

Working in groups or individually, players sort the exact same **18 specimens** three separate times, organizing them across three different attributes:
* **Size**
* **Colour**
* **Texture**

## Key Takeaways & Discussion Prompts

* **Compare across lenses:** See how identical specimens cluster differently depending on the attribute you prioritize.
* **Spot the edge cases:** Notice how boundary-crossing items force arbitrary cutoffs, awkward trade-offs, or newly invented categories.
* **Question digitization:** Reflect on how rigid digital schemas flatten physical nuance when representing real-world objects.
